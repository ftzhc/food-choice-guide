# 食品えらびガイド

福岡天神頭痛と肺のクリニックのスタッフが、栄養指導のときに患者さんと一緒に見るための「食品えらびの目安表」です。
ふだんよく食べる食品・料理をさがすと、病名ごとに **◎（おすすめ）○（ふつうに食べてよい）△（量や回数に注意）×（なるべく控える）** の印と、ひとことの理由が表示されます。

> **大事な注意**
> このガイドの印・理由・数字は、すべて**下書き**です。日本の主な診療ガイドラインと「日本人の食事摂取基準」の一般的な考え方をもとに付けていますが、公開前に**医師・管理栄養士の確認**が必要です。確認してほしい点は [CHECKLIST.md](CHECKLIST.md) にまとめています。
> 画面の下にある「医師・管理栄養士確認：未」は、確認がすむまでそのままにしてください。

---

## 1. できること

- 病名を選ぶ（いくつでも）：**高血圧症・脂質異常症・2型糖尿病・高尿酸血症・鉄欠乏性貧血・低アルブミン血症**
- 「腎臓の病気がある・透析中」にチェックすると、たんぱく質・カリウムの多い食品に「医師の指示に従ってください」の注意が付き、低アルブミン血症の ◎（たんぱく質をとる）は表示されなくなります
- 食品名の検索（ひらがな・カタカナ・漢字のどれでも）、分類での絞り込み、「△と×だけ表示」「◎だけ表示」の切り替え
- 食品ごとのカードに、1回量の目安・病名ごとの印と理由・おおよその数字・「かわりにおすすめ」の食品を表示
- 病名を選ぶと、その病名の「選び方のコツ」を上に表示

スマホ・タブレット・パソコンのどれでも見られます。何も保存せず、外部との通信もしません（ログインや登録もいりません）。

## 2. 使い方（画面の操作）

1. **病名を選ぶ**：画面の上の病名を押してチェックを入れます。選んだ病名の印だけが表示されます。何も選ばないと、6つすべての印が表示されます。
2. **腎臓の病気がある・透析中**：当てはまる患者さんのときにチェックします。
3. **食品をさがす**：検索欄に「らーめん」「ビール」のように入れます。カタカナでも漢字でも見つかります。
4. **分類で絞る**：「主食」「肉」「お酒」などのボタンを押します。
5. **表示の切り替え**：「△と×だけ表示」で気をつける食品だけ、「◎だけ表示」でおすすめだけを見られます。
6. **カードの見方**
   - 1回量の目安（例：ラーメン1杯）
   - 病名ごとの印と理由（印は色だけでなく、記号と文字でも分かります）
   - おおよその数字（選んだ病名に関係の深い数字を先に表示。プリン体だけは100gあたり、ほかは1回量あたり）
   - 「かわりにおすすめ」の食品名を押すと、その食品を検索できます
7. 「条件をクリア」で最初の状態に戻ります。

### 印の意味

| 印 | 意味 |
|---|---|
| ◎ | おすすめ（その病気によい働きがある、積極的にとりたい） |
| ○ | ふつうに食べてよい（ふだんの量なら問題なし） |
| △ | 量や回数に注意（減らす・工夫すれば続けられる） |
| × | なるべく控える（食べるなら特別な日に少量） |

## 4. 食品を足す・印を直す方法

食品のデータは `index.html` の中ほど、**「■ 食品データ（ここから）」** と書かれた部分にまとまっています。プログラムの知識がなくても、ここを書きかえるだけで画面に反映されます。

### 手順（GitHub の画面で直す場合）

1. GitHub でこのリポジトリを開き、`index.html` を押す
2. 右上の鉛筆マーク（Edit）を押す
3. 「食品データ」の部分を書きかえる（下のルールを参照）
4. 右上の「Commit changes」を押し、「変更した内容」を一言書いて確定する
5. 数分すると公開ページに反映されます（画面を再読み込みしてください）

### 1つの食品の書き方

```js
  {
    "名前": "ラーメン（とんこつ）",
    "よみ": "らーめん",
    "別名": ["とんこつラーメン", "中華そば"],
    "分類": "汁物・麺類",
    "目安量": "1杯（麺とスープを含む。約600g）",
    "高血圧症": "× 食塩が1杯で1日の目安に近い。スープを残すと半分近く減らせる",
    "脂質異常症": "× とんこつスープは動物性の脂が多い。スープを残し、替え玉はしない",
    "2型糖尿病": "△ 麺の糖質が多い。替え玉はせず、野菜やゆで卵を足す",
    "高尿酸血症": "△ スープにプリン体が溶け出ている。スープを残す",
    "鉄欠乏性貧血": "○ 鉄は少なめ。チャーシューやゆで卵で少し補える",
    "低アルブミン血症": "○ チャーシューと卵でたんぱく質はとれる。塩分と脂に注意",
    "数字": { "エネルギーkcal": 550, "食塩g": 5.5, "たんぱく質g": 22, "糖質g": 70 },
    "かわりに": ["そば", "うどん"],
    "腎注意": "たんぱく質・カリウム",
    "ひとこと": "数字はスープを全部飲んだ場合"
  },
```

### ルール

- **印を直す**：病名の欄の最初の1文字（◎ ○ △ ×）を書きかえます。そのあとに**半角の空白**を1つ入れて、理由を書きます。
- **理由**：40字くらいまで。やさしい言葉で。△や×には「どうすればよいか」を入れます。
- **食品を足す**：どれかの食品のかたまり（`{` から `},` まで）をコピーして、同じ分類のところに貼り、中身を書きかえます。かたまりの最後の `,` を忘れないでください。
- **食品を消す**：そのかたまりを `{` から `},` まで消します。
- **よみ**：ひらがなで。検索に使います。「別名」には、カタカナや別の言い方を入れておくと見つけやすくなります。
- **数字**：おおよその値でかまいません。分からないものは、その行ごと消してください。プリン体だけは100gあたり、ほかは1回量あたりです。
- **腎注意**：`""`（なし）、`"たんぱく質"`、`"カリウム"`、`"たんぱく質・カリウム"` のどれか。目安は、1回量でたんぱく質8g以上、カリウム300mg以上です。
- **かわりに**：この表にある食品の「名前」をそのまま書くと、画面で押せるボタンになります。
- 文字は `"`（半角のダブルクォート）で囲みます。全角の「”」は使えません。
- 書き方をまちがえると、画面の上に「食品データに直したい点があります」と出ます（印が読めない、かわりの食品名が見つからない、など）。その案内に沿って直してください。
- 直したら、画面の下の「最終更新日」も変えてください（`index.html` の `const 最終更新日 = "……"` の部分）。医師・管理栄養士の確認がすんだら `const 確認状況 = "……"` も書きかえます。

### 「選び方のコツ」や印の意味を直す

`index.html` の「■ 病名と『選び方のコツ』」の部分に、病名ごとに3〜5行ずつ書いてあります。文章を書きかえるだけで反映されます。

## 5. GitHub Pages で公開する手順

1. GitHub でこのリポジトリを開く
2. 上の「Settings」を押す
3. 左の「Pages」を押す
4. 「Build and deployment」の「Source」が「Deploy from a branch」になっていることを確認する
5. 「Branch」で `main` を選び、フォルダは `/ (root)` のまま「Save」を押す
6. 1〜2分待って同じページを開き直すと、上に「Your site is live at https://（ユーザー名）.github.io/food-choice-guide/」と表示されます。これが公開ページのアドレスです
7. 以後、`index.html` を書きかえて確定（Commit）するたびに、数分で公開ページも更新されます

> 公開ページは誰でも見られます。患者さんの個人情報は、このリポジトリにもページにも絶対に入れないでください。

## 7. 技術的な条件

- `index.html` 1ファイルに HTML・CSS・JavaScript をまとめています。GitHub Pages にそのまま置けます
- 外部ライブラリ・CDN・Webフォント・外部サイトへの通信は使っていません。サーバー・データベース・ログインも不要です
- 何も保存しません（閲覧の記録、入力した内容、選んだ病名などは残りません）
- 個人情報・パスワード・APIキーは含まれていません
